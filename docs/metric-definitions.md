# 指标定义

> 本文档中的业务对象与口径均为脱敏模拟，仅用于 Demo。

## 支付销售额

- 定义：支付成功订单的含税成交金额，不含取消订单。
- 时间归属：按支付成功时间归属自然日。
- 默认单位：人民币元。
- 注意：不能与下单金额、发货金额或回款金额混用。

## 区域

- 华北：北京、天津、河北。
- Demo 暂不展示跨区订单的复杂归属规则。

## 环比

- 本例用于回答昨日异常，比较昨日与前一自然日。
- 若遇节假日或活动日，必须补充同星期或活动基线，不能仅凭单日环比下结论。

## 访问量与支付转化率

- 访问量：当天进入指定经营范围的有效会话数。
- 支付转化率：支付成功订单数 / 有效会话数。
- 漏斗指标只用于解释变化结构，不能自动证明因果。
